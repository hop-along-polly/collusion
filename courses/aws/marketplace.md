# AWS Marketplace

A study track rather than a certification. It covers selling software through AWS Marketplace:
the commercial model every listing shares, the mechanics that differ per listing type, and the
API surface a Seller integrates against.

## Topics covered

Start with Commercials - the model below applies to every listing type, and the per-listing
mechanics make little sense without it.
